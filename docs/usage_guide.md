# Usage guide

Start with the [notebook gallery](gallery.md), then open the example for the model or feature of interest. Notebook paths and data paths are generally relative to the notebook directory or the repository checkout; check each notebook's setup cells before executing it.

For a local rendered site, run:

```bash
make docs-serve
```

The rendered site uses stored notebook outputs and does not execute cells. See the [audit status](audit.md) and [build and execution guide](workflow.md) before treating an example as a runnable model workflow.
