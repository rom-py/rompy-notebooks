# Notebook catalogue

The catalogue is the complete reference index for published notebooks. Use the views below to browse by model, topic, or the complete inventory.

- [All notebooks](generated/all-notebooks.md) — every published notebook, exactly once.
- [By model](generated/notebooks-by-model.md) — browse SWAN, XBeach, and SCHISM collections.
- [By topic](generated/notebooks-by-topic.md) — find notebooks by capability or concept.

For a guided introduction, start with [Learning journeys](swan-journey.md) and choose a model.
