# rompy-notebooks

Examples and tutorials for configuring ocean models with the [rompy](https://github.com/rom-py/rompy) ecosystem.

Start with [Start here](installation_guide.md) for setup and Rompy concepts. Choose a [learning journey](swan-journey.md) to learn a model progressively, or use the [notebook catalogue](catalogue.md) as the single reference index. The [build and execution guide](workflow.md) explains how to render the site and how that differs from executing a model.

!!! note
    The documentation site renders the outputs stored in notebooks; it does not execute notebook cells or model binaries.
