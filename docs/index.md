# rompy-notebooks

Examples and tutorials for configuring ocean models with the [rompy](https://github.com/rom-py/rompy) ecosystem.

Start with the [SWAN learning journey](swan-journey.md) for a guided path from Rompy concepts to a complete model workspace. Use the [notebook gallery](gallery.md) to browse the full reference collection by model. The [build and execution guide](workflow.md) explains how to render the site and how that differs from executing a model.

!!! note
    The documentation site renders the outputs stored in notebooks; it does not execute notebook cells or model binaries.
