# XBeach

XBeach has a seven-lesson learning journey plus focused data-interface and component material. The journey is the recommended entry point for users learning Rompy and XBeach together.

## Recommended path

The journey is complemented by focused tutorials in the catalogue.

Start with the [XBeach learning journey](../xbeach-journey.md), then follow the lessons in order. The [XBeach catalogue](../generated/notebooks-by-model.md#xbeach) provides the complete reference view.

## Coverage

The collection covers procedural and declarative workflows, grids, bathymetry, wind and wave forcing, physics, sediment, boundaries, outputs, hotstarts, MPI, and execution guidance. Full scientific runtime validation remains environment-dependent. See the [coverage matrix](coverage.md).

!!! note
    Documentation builds render notebooks without executing XBeach. Runtime-dependent lessons require an appropriate `rompy-xbeach` environment and XBeach installation.
