# SCHISM notebooks

SCHISM currently has one broad procedural demonstration. It is useful for understanding the shape of a Rompy SCHISM setup, but it is not yet a complete beginner journey or a comprehensive reference collection.

!!! note
    Documentation builds render the notebook without executing SCHISM. Running the demonstration requires the SCHISM runtime and its input data.

## Getting started and procedural workflow

- [SCHISM procedural demonstration](../notebooks/schism/schism_demo.ipynb)

The demonstration covers a procedural configuration, grid and input-data setup, and the boundary between generating a workspace and running the model.
